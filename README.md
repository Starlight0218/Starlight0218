# Featured Capstone Project

## Multiplayer 2D Space Arcade Game

<div align="center">

![Capstone Gameplay Screenshot](images/capstone-gameplay.jpg)

</div>

For my Capstone project, I worked on a browser-based **multiplayer 2D space arcade game** built with **Phaser**, **Socket.io**, **Node.js**, **JavaScript**, **HTML**, and **CSS**.

The game focuses on real-time multiplayer gameplay in a large 2D space environment. Players can move around the world, collect stars, use different ships/classes, interact with UI systems, and track activity through gameplay elements such as the HUD, level menu, and minimap.

This project represents one of my strongest examples of working in a larger codebase, connecting multiple systems together, and improving both gameplay functionality and user experience.

## My Capstone Contributions

During the Capstone project, I helped improve the game’s user interface, gameplay flow, and client-side systems. My work focused on making the player experience clearer, smoother, and easier to use.

Some of my main contributions included:

- Improving the level menu and ship selection experience
- Working on purchasable ship UI behavior
- Helping connect UI elements to player data
- Updating minimap behavior and indicators
- Improving how players and stars appear on the minimap
- Testing UI and gameplay behavior
- Helping polish the overall player experience
- Using GitHub branches and commits to manage project changes

This project helped me practice working with real-time systems, larger JavaScript files, client-side game architecture, and the process of building features that depend on multiple parts of the codebase.
